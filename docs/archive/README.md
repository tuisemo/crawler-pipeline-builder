# Archive Notes

`docs/archive/` keeps historical planning and redesign material that may still be useful as background context.

## What belongs here

- refactor roadmaps
- architecture review notes
- future-looking design plans
- redesign proposals

## What does not belong here

- current product usage guides
- code-accurate architecture documentation
- active contributor onboarding material

## Important Rule

Files in `docs/archive/` are **not** the source of truth for the current repository behavior.

When an archived file conflicts with:

- the code
- `README.md`
- `DESIGN.md`
- `docs/product-guide.md`
- `docs/technical-guide.md`

the current code and active docs win.
